# DrinkItUp

Drink It Up is an Android game where players create drinks by selecting the correct ingredients based on clues within a limited time. The game features a scoring system that allows players to compete for higher scores. 
You can test the demo here: https://appetize.io/app/b_4cvdnd2usimbmragsxwtnvftkm
